Pengaturan scraper berita

Feed RSS/Atom per kategori. Switch Aktifkan scraper (master) dan switch Aktif di tiap kategori tersimpan otomatis. Mengaktifkan atau menonaktifkan switch master akan menerapkan status yang sama ke semua kategori.

Umum

Saat nonaktif, scraping hanya berjalan untuk kategori yang aktif satu per satu. Mengubah switch ini juga menyamakan semua switch kategori dan menyimpannya otomatis.

Feed per kategori

Satu atau lebih URL per kategori, pisahkan dengan koma. Pilih Penulis (user CMS) per kategori — post hasil scrape memakai akun tersebut. Mode gambar: Scrape gambar, Cari di web (Auto: Pexels → Unsplash → Pixabay → … — API key ada di Pengaturan situs → API gambar web; tidak memakai gambar dari artikel sumber; jika pencarian gagal, fallback ke cover template), Pakai template, dan Generate AI (butuh key OpenAI atau Gemini). Nonaktifkan Aktif untuk melewati scraping kategori tersebut. Switch kategori juga tersimpan otomatis. Mendukung feed RSS/Atom dan pola sitemap WordPress seperti https://domain.com/post-sitemap1.xml; angka di belakang akan dinaikkan otomatis.
